# Taller Integrador

Aplicación web desarrollada como parte del Taller Integrador.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Descripción

La aplicación permite trabajar con el promedio de tres calificaciones ingresadas por el usuario.

## Control de versiones

El proyecto utiliza Git y GitHub para gestionar los cambios mediante ramas, commits y Pull Requests.

## Rama de desarrollo

Los cambios se realizan mediante ramas independientes antes de integrarse a la rama principal.
